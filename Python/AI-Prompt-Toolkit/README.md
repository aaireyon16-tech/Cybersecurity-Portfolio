# AI Prompt Toolkit

## Overview

AI Prompt Toolkit is a simple Python application that helps organize and search AI prompts.

The application allows users to save prompts by category, browse saved prompts, and search for prompts using keywords. This project demonstrates Python fundamentals while building a practical utility for working with generative AI.

## Technologies Used

- Python 3

## Skills Practiced

- Dictionaries
- Lists
- Loops
- Conditional statements
- User input
- String searching
- Data organization

## Features

- Add prompts
- Organize prompts by category
- View saved prompts
- Search prompts by keyword

## Future Improvements

Future versions will include:

- Save prompts to a file
- Edit prompts
- Delete prompts
- Prompt ratings
- Tags
- AI-assisted prompt evaluation
- Export prompts
