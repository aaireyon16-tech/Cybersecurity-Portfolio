# Password Generator

## Overview

This Python application generates a random password based on a user-specified length.

The project demonstrates the use of Python's built-in `random` and `string` libraries while reinforcing core programming concepts such as variables, loops, user input, and string manipulation.

## Technologies Used

- Python 3

## Skills Practiced

- User input
- Variables
- Loops
- String manipulation
- Python standard library
- Random number generation

## Future Improvements

Future versions of this project will allow users to:

- Choose whether to include uppercase letters
- Include or exclude numbers
- Include or exclude special characters
- Generate multiple passwords
- Evaluate password strength
